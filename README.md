# 🧠 NeuroVision: Explainable Brain MRI Classification

**Developed by Team Chino Coders**  
**ML × ACS Hackathon 2026 | Medical Imaging & Explainable Artificial Intelligence**

Python 3.10+ · PyTorch · TorchVision · Streamlit · Grad-CAM · License: MIT

NeuroVision is an interactive machine learning-based brain MRI classification research and educational prototype developed by **Chino Coders**. It explores the classification of brain MRI images into four categories—Glioma, Meningioma, Pituitary Tumor, and No Tumor—alongside explainable AI techniques to help visualize regions influencing model predictions.

### Team Contributions

Team Chino Coders focuses on developing an interactive brain MRI classification platform that combines deep learning, medical image analysis, and explainable artificial intelligence.

The project explores ResNet50, EfficientNet-B0, and a Custom CNN, with the objective of building a reproducible workflow for MRI image classification, model evaluation, and interactive visualization.
